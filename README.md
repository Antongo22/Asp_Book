# Учебник по ASP.NET Core

Полное руководство для начинающих разработчиков по изучению ASP.NET Core. Каждая глава содержит теорию, демонстрацию, практическую задачу и подробные ответы с объяснениями.

## Структура проекта

Проект состоит из 13 отдельных приложений:

- **Gateway** (порт 5000) - главная страница с навигацией по всем главам
- **Chapter 01** (порт 5001) - Начало работы: Middleware, REST API, Swagger
- **Chapter 02** (порт 5002) - Dependency Injection
- **Chapter 03** (порт 5003) - HTTP Requests, HttpClient
- **Chapter 04** (порт 5004) - Error Handling, Custom Middleware
- **Chapter 05** (порт 5005) - Razor Pages UI
- **Chapter 06** (порт 5006) - Entity Framework, DTO, Migrations, SQLite
- **Chapter 07** (порт 5007) - Authentication vs Authorization, JWT
- **Chapter 08** (порт 5008) - Refresh Tokens
- **Chapter 09** (порт 5009) - WebSockets
- **Chapter 10** (порт 5010) - SignalR
- **Chapter 11** (порт 5011) - Авторизация с SignalR/WebSockets
- **Chapter 12** (порт 5012) - Тестирование API и EF, In-Memory БД

## Требования

- .NET 10.0 SDK или выше
- Docker и Docker Compose (для запуска всех проектов одновременно)
- Любой редактор кода (Visual Studio, VS Code, Rider и т.д.)

## Запуск проекта

### Локальный запуск (один проект)

Для запуска отдельного проекта:

```bash
# Перейдите в папку проекта
cd Asp_Book.Chapter01

# Восстановите зависимости
dotnet restore

# Запустите проект
dotnet run
```

Проект будет доступен по адресу `http://localhost:5001` (номер порта зависит от главы).

### Запуск через Docker Compose (все проекты)

Для запуска всех проектов одновременно:

```bash
# Из корневой папки проекта
docker-compose up --build
```

Все проекты будут доступны на своих портах (5000-5012).

Для остановки:
```bash
docker-compose down
```

## Структура каждой главы

Каждая глава содержит:

1. **Теория** - подробное объяснение концепций с примерами кода
2. **Демонстрация** - рабочие примеры, которые можно запустить и протестировать
3. **Задача** - практическое задание для самостоятельного выполнения
4. **Ответы** - подробное решение задачи с объяснениями

### Навигация по главам

1. Откройте Gateway: `http://localhost:5000`
2. Выберите нужную главу из списка
3. Изучите теорию и демонстрацию
4. Выполните задачу самостоятельно
5. Проверьте ответы и объяснения

### Swagger UI

Для тестирования API каждой главы доступен Swagger UI:
- Глава 1: `http://localhost:5001/swagger`
- Глава 2: `http://localhost:5002/swagger`
- И так далее...

## Содержание глав

### Глава 1: Начало работы
- Что такое Middleware и как работает ASP.NET
- REST API и его принципы
- Swagger для документирования API
- Создание простого контроллера
- **Задача:** API калькулятор

### Глава 2: Dependency Injection
- Паттерн Dependency Injection
- Регистрация сервисов
- Жизненные циклы сервисов (Transient, Scoped, Singleton)
- Использование ILogger
- **Задача:** Создать сервис и внедрить его

### Глава 3: HTTP Requests
- HttpClient для запросов к внешним API
- Настройка HTTP клиентов
- Обработка ответов и ошибок
- **Задача:** Интеграция с внешним сервисом

### Глава 4: Error Handling
- Глобальный обработчик ошибок
- Создание кастомного middleware
- Обработка исключений
- **Задача:** Создать middleware для логирования

### Глава 5: Razor Pages UI
- Что такое Razor Pages
- Синтаксис Razor
- Model Binding
- Работа с формами
- **Задача:** Создать форму с валидацией

### Глава 6: Entity Framework
- EF Core и DbContext
- DTO (Data Transfer Objects)
- Миграции базы данных
- Работа с SQLite
- CRUD операции
- **Задача:** Создать модель и миграции

### Глава 7: Authentication и Authorization
- Разница между Authentication и Authorization
- JWT токены
- Генерация и валидация токенов
- Интеграция JWT в Swagger
- **Задача:** Реализовать авторизацию

### Глава 8: Refresh Tokens
- Механизм refresh токенов
- Обновление access токенов
- Хранение токенов
- **Задача:** Реализовать refresh token flow

### Глава 9: WebSockets
- Что такое WebSockets
- Низкоуровневая работа с WebSockets
- Отправка сообщений одному и всем
- **Задача:** Создать простой чат

### Глава 10: SignalR
- Что такое SignalR
- Hubs и Groups
- Отправка сообщений одному и всем через SignalR
- **Задача:** Улучшить чат с SignalR

### Глава 11: Авторизация с SignalR/WebSockets
- Аутентификация в real-time соединениях
- Защита WebSocket/SignalR соединений
- **Задача:** Добавить авторизацию в чат

### Глава 12: Тестирование
- Unit тесты
- Интеграционные тесты
- In-Memory база данных для тестирования
- Тестирование API и EF
- **Финальная задача:** Создать полноценный чат с группами и несколькими пользователями

## Рекомендации по изучению

1. **Изучайте последовательно** - каждая глава строится на предыдущих
2. **Практикуйтесь** - выполняйте все задачи самостоятельно
3. **Экспериментируйте** - изменяйте код и смотрите, что происходит
4. **Используйте Swagger** - тестируйте API через Swagger UI
5. **Читайте ответы** - даже если решили задачу, прочитайте ответы для лучшего понимания

## Troubleshooting

### Порт уже занят
Если порт занят, измените его в `Properties/launchSettings.json` соответствующего проекта.

### Ошибки при запуске Docker
Убедитесь, что Docker запущен и порты 5000-5012 свободны.

### Ошибки компиляции
Выполните `dotnet restore` и `dotnet clean`, затем `dotnet build`.
